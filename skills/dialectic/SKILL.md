---
name: dialectic
description: Use when you need to compare two things or to pressure-test the assumption.
---

Frame the position:

- Comparison ("A vs B"): one goes as the thesis, the other as the antithesis.
- A single argument: use as the thesis, infer the antithesis.

Spawn 2 subagents:

- Agent 1 (thesis): build the strongest possible case for the position.
- Agent 2 (antithesis): strongest possible case against the position.

Present both agents findings, then make synthesis from them — either produce a stronger position or pick a clear winner if one side won.
